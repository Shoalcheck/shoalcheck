Before the change

Three questions, asked at the moment you type the change.

A preflight reads only the kinds its question needs, in seconds, and its exit code is the answer — so it goes into a runbook or a pipeline as it is.

Can these nodes be evacuated?

shoalcheck preflight drain node-1
  • Disruption budgets that allow zero evictions
  • Volumes pinned to the node or its zone
  • Pods with no other node that fits their requests, selectors, affinity and taints

Questions

What people ask before they run it on production.

Does it install anything in my cluster?

No. It is a binary on your machine that talks to the Kubernetes API with your kubeconfig, issuing get and list. There is no agent, operator, CRD or webhook, and nothing to uninstall.

What access does it need?

Read access to the kinds it lists — shoalcheck audit --show-permissions prints them before it connects. With less, it still runs, and says which kinds it could not read and why. A refused read is never reported as a clean one.

Does any data leave my machine?

No. The binary sends nothing to us or to anyone else, and the report is a file you keep. It talks to your API server and, when one is reachable, to Prometheus — and to nothing else unless you run shoalcheck update, which fetches signed reference data.

Which clusters does it work with?

Any conformant Kubernetes cluster it can reach. Costs are priced from bundled list prices for EKS, AKS and GKE; on any other cluster a figure says “unpriced” rather than inventing a rate.

What counts as a cluster on my plan?

A distinct cluster, by its kube-system UID, read with a licence in any 30 days — counted on your machine. Reading the same cluster again costs nothing, and preflight is never counted.

How is the licence checked?

Offline. A key is a signed document naming your plan, its expiry and its cluster cap, and the binary verifies the signature without phoning home. Paste it into the app, or run shoalcheck licence install.

What does the free plan include?

Preflight in full, and shoalcheck audit without a key: the reading's opening and its five largest problems in the terminal, with how many more there are. Nothing is saved, written or exported.

Why does my computer warn me when I open it?

The first releases are not yet notarized by Apple or code-signed for Windows. Each release publishes the archives' SHA-256 sums, signed with cosign, so you can check what you downloaded with cosign verify-blob and the public key beside the releases.
